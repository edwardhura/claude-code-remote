# Context: core

## Files
- pyproject.toml — project metadata, runtime + dev deps, ruff/mypy/pytest config, `[project.scripts] ccr = "ccr.cli:main"`.
- uv.lock — generated lockfile produced by `uv sync`.
- .gitignore — ignores Python build artefacts, `.venv/`, `data/`, `.env`, IDE files, ruff/mypy caches.
- .env.example — minimal placeholder carrying only the keys CCR-003's Settings needs; CCR-002 will replace it with the full Section 7 template.
- src/ccr/__init__.py — exposes `__version__ = "0.1.0"`.
- src/ccr/__main__.py — `python -m ccr` entrypoint that calls `ccr.cli:main`.
- src/ccr/cli.py — argparse skeleton; calls `configure_logging` before dispatch; `init-db` programmatically runs `alembic upgrade head` and ensures `DATA_DIR` + `DATA_DIR/logs` exist; remaining handlers still raise `NotImplementedError`. Exposes `build_parser()` for tests.
- src/ccr/config.py — `Settings(BaseSettings)` covering every Section 7 env var; field validators enforce JWT_SECRET ≥ 32 chars, WEB_PORT 1–65535, TOKEN_TTL_SECONDS 60–86400, and parse PROXY_PORT_ALLOWLIST to `set[int] | None` (blank ⇒ None).
- src/ccr/logging_setup.py — `configure_logging(level)` wires structlog + stdlib logging to a console renderer; idempotent.
- src/ccr/db/__init__.py — re-exports `Base`, `PairedUser`, `PairingCode`, `Session`.
- src/ccr/db/models.py — SQLAlchemy 2 `DeclarativeBase` and the three persistent tables; UUIDs as `Uuid(as_uuid=True)`; partial unique index on `is_owner = true` enforces single-owner invariant.
- src/ccr/db/engine.py — `create_engine_from_settings`, `AsyncSessionMaker`, `get_session` async context manager committing on success / rolling back on error.
- alembic.ini — `sqlalchemy.url = sqlite+aiosqlite:///data/ccr.db`, `script_location = alembic`.
- alembic/env.py — async-aware Alembic env importing `Base.metadata` from `ccr.db.models`.
- alembic/script.py.mako — template for future autogenerated revisions.
- alembic/versions/0001_initial.py — hand-written initial migration creating `paired_users`, `pairing_codes`, `sessions` plus indexes (single-owner partial unique, `pairing_codes(tg_user_id, used_at)`, `sessions(status)`, `sessions(started_at desc)`).
- tests/test_cli.py — covers `--help`, unknown subcommand, missing subcommand, dispatch to `NotImplementedError`, and end-to-end `python -m ccr` subprocess invocations.
- tests/test_config.py — Settings loads from a temp `.env`; rejects short JWT_SECRET, out-of-range WEB_PORT and TOKEN_TTL_SECONDS; parses PROXY_PORT_ALLOWLIST including blank → None and whitespace handling; defaults verified.
- tests/test_db_models.py — in-memory SQLite engine + `Base.metadata.create_all`; CRUD for each model; partial-unique owner index raises `IntegrityError` on a second `is_owner=True`; unique `tg_user_id`; unique pairing `code`.
