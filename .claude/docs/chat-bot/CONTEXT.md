# Context: chat-bot

## Files
- `src/ccr/bot/__init__.py` — empty package marker
- `src/ccr/bot/handlers/__init__.py` — empty package marker
- `src/ccr/bot/middlewares.py` — `AllowlistMiddleware`: extracts sender from Message/CallbackQuery, checks `auth.allowlist.is_paired`, injects `is_paired_user` into aiogram data, persists `last_chat_id` on paired senders, short-circuits non-`/start` traffic from unpaired senders (NOTE: pre-existing F1 advisory — unpaired callback-query tap does not call `cb.answer()`, leaving Telegram spinner hanging; track as separate ticket)
- `src/ccr/bot/notify.py` — `notify_owner` (queries owner row, sends to `last_chat_id`, warns if no owner/null chat_id); `broadcast_paired` (fans out to all paired users with non-null `last_chat_id`, skips `exclude` set, swallows per-recipient `TelegramAPIError`)
- `src/ccr/bot/handlers/pairing.py` — `/start` handler with three branches: paired status reply; bootstrap (no owner) reply with code + approve command; normal path reply + `notify_owner` with code. Note: username is interpolated unescaped in HTML mode (F1 advisory — harden with `html.escape()` when adding more HTML messages in CCR-008)
- `src/ccr/bot/keyboards.py` — `permission_kb(session_id, request_id, options) -> InlineKeyboardMarkup`: builds one button per option using `_LABELS` map for display text; unknown options fall back to `opt.capitalize()`; `callback_data=f"perm:{session_id}:{request_id}:{choice}"`
- `src/ccr/bot/app.py` — `build_dispatcher(settings, db_factory, session_manager=None) -> tuple[Bot, Dispatcher]` (registers `AllowlistMiddleware`, stashes `db_factory`, `session_manager`, and `settings` in workflow data, includes pairing router, session router, and permission router); `run_polling` (logs `"Bot started, awaiting updates"` then enters `dp.start_polling(bot)`)
- `src/ccr/bot/formatting.py` — `chunk_text` and `event_to_messages(event: ClaudeEvent) -> list[OutboundMessage]` where `OutboundMessage = tuple[str, InlineKeyboardMarkup | _PendingKeyboard | None]`; `PermissionRequest` branch returns a `_PendingKeyboard` sentinel (pure function cannot access session_id); result line: `✅ done · {s}s · {N}k tokens`; all user-controlled strings escaped via `html.escape()`
- `src/ccr/bot/handlers/session.py` — `/new`, `/stop`, `/clear`, `/who`, `/pid`, `/sessions`, `/continue` command handlers plus `handle_text` plain-text handler (filter narrowed to `F.text & ~F.text.startswith("/")` so slash commands fall through to passthrough router); `/new` and `/clear` replies include `(pid <N>)`; `/clear` also broadcasts a `_DIVIDER_MESSAGE` ("— — — new session — — —") to all paired chats via `broadcast_paired` between `manager.stop()` and `manager.new_session()`, gated on `prior_status != IDLE` (read before stop) so an idle `/clear` does not post a misleading divider; `/pid` shows session id, pid, and uptime; `/sessions` lists up to 20 most-recent session rows (newest first) with HTML-escaped id8, status, started_at, truncated first_prompt, and tg_user fields; empty DB returns stable `"(no sessions)"` string; body capped at 3500 chars via `chunk_text`; `/continue` calls `manager.continue_session()`, replies `"Session <id8> resumed (pid <N>)."`, catches `SessionAlreadyRunningError` and `NoPriorSessionError` with canned strings, catches bare `SessionError` with HTML-escaped message
- `src/ccr/bot/handlers/passthrough.py` — catch-all slash-command router registered last in `app.py`; `WHITELIST = frozenset({"model", "compact"})` forwarded via `send_slash` (`"cost"` lifted out in CCR-023); `BLOCKED_INTERACTIVE = {"mcp", "init"}` returns canned local-terminal redirect; `/agents` handled by dedicated early-return branch rendering Running (live subagents from `SessionManager.running_subagents()`) and Library (`.claude/agents/*.md` glob) sections in HTML; `/skills` branch renders a single "Skills" section from `SessionManager.available_skills()` with HTML-escaped names and `"(none)"` empty-state placeholder; `/cost` handled by dedicated `_reply_cost` branch that calls `session_manager.current_session_usage()` and renders an HTML reply with tokens (input/output/cache), tool-use count, elapsed time, session id8, and optionally cost in USD (omitted for subscription users when `total_cost_usd == 0`); `/usage` handled by dedicated `_reply_usage` branch (CCR-032) that calls `session_manager.current_rate_limit_status()` and renders an HTML reply with rate-limit window, used/limit counts, reset times, and `is_using_overage` flag; three reply states: no active session / no rate-limit data yet / full render; returns `"No active session."` when idle; unknown commands return the stable usage hint listing all whitelisted commands including future Phase 13 entries
- `src/ccr/bot/handlers/permission.py` — `cb_permission` callback-query handler matching `F.data.startswith("perm:")`; parses `perm:{session_id}:{request_id}:{choice}`; validates choice against `_pending_options` frozenset; handles stale session, stale request, forged choice, malformed data, concurrent taps (via `contextlib.suppress(TelegramBadRequest)`), missing username, edit failure; edits message to remove keyboard and append `→ {choice} (by @{username})` with HTML escaping
- `src/ccr/bot/typing.py` — `TypingKeepalive` class: per-chat task sending `send_chat_action("typing")` every 4s while a session is producing events; swallows `TelegramAPIError`; lifecycle mirrors `_ChatSender` (`start`/`cancel`/`wait_closed`)
- `src/ccr/server.py` — `async serve(settings)` runs bot polling, `_broadcast_loop`, and `_typing_loop` concurrently; `_ChatSender` per-chat queue; `_broadcast_loop` takes `manager: SessionManager`, materialises `_PendingKeyboard` sentinels via `_materialise_keyboards`, special-cases `PermissionRequest` (flush buffer + send immediately), buffers non-permission events while gate is paused, drains buffer on gate reopen; `_ChatSender._run` unpacks `OutboundMessage` tuple and passes `reply_markup` to `bot.send_message`; `TypingKeepalive` tasks started/cancelled per session event stream
- `src/ccr/cli.py` — `_cmd_serve` wires `serve` subcommand to `asyncio.run(server.serve(Settings()))`
- `tests/test_bot_session.py` — extended with four `cmd_sessions` tests (empty DB, 3-row ordering, long-prompt truncation, status passthrough) plus a `_seed_session` helper
- `tests/test_orphan_reconcile.py` — new file with four tests covering reconcile contract (running→crashed, exit_reason, ended_at populated, second call is no-op)
- `tests/test_bot_pairing.py` — 7 tests covering all four acceptance paths: bootstrap, normal, already-paired, unpaired plain text rejection, plus middleware pass-through scenarios
- `tests/test_bot_permission.py` — 17 tests covering keyboard shape, `_parse_callback`, every handler edge case (stale id, stale request, forged choice, malformed data, concurrent taps, missing username, edit failure, HTML escape)
- `tests/test_formatting.py` — updated for new `OutboundMessage` tuple shape; includes `test_permission_request_returns_message_with_keyboard_sentinel` and `test_permission_request_html_escapes_tool_name_and_input`
- `tests/test_broadcast.py` — includes `test_broadcast_permission_message_carries_keyboard`, `test_broadcast_buffers_text_event_during_permission_then_drains_in_order`, `test_broadcast_sse_subscriber_not_paused`
- `tests/test_typing.py` — 8 tests covering `TypingKeepalive` firing, looping, error swallowing, idempotent cancel/start, and `_typing_loop` integration
- `tests/test_bot_continue.py` — 7 tests: happy-path reply, already-running canned string, no-prior canned string, other `SessionError` HTML-escaped, valid 8-hex prefix forwards `session_id_prefix` kwarg, invalid-format rejected without manager call (5 inputs), unknown prefix returns not-found canned string
- `tests/test_bot_passthrough.py` — renamed from `tests/test_passthrough.py` (CCR-023); extended with `/skills` tests (active session with skills, empty skills array, no active session, HTML escaping of skill names, `/skills` removed from unknown-command fallthrough); extended with 7 new CCR-023 `/cost` tests (rich HTML reply, no-active-session canned string, cost-line omission for subscription users, HTML-escape on session id, multi-minute elapsed format, `/model`+`/compact` whitelist regressions, explicit `send_slash` non-call assertion); previously 15 tests covering `/agents` Running+Library rendering, empty-state placeholders, HTML escaping, alphabetical sort, non-md/hidden file skipping, `/mcp` and `/init` regression, and unknown-command hint
- `tests/test_session_manager.py` — extended with two CCR-022 tests: `test_running_subagents_tracks_agent_tool_use_and_clears_on_result`, `test_running_subagents_ignores_non_subagent_tools`; extended in CCR-030 with tests for `available_skills()` and `is_session_active()` accessors; extended in CCR-023 with three tests for `current_session_usage()`: idle returns None, live session aggregates JSONL via fake_claude, returns None after `stop()`
- `src/ccr/claude/manager.py` — (cross-listed from claude-runtime) CCR-030 added `available_skills() -> list[str]` (reads `_skills` snapshot from most-recent `SystemInit` event) and `is_session_active() -> bool` accessors; `_skills: list[str]` instance attribute tracked on `SystemInit` events; CCR-023 added `current_session_usage() -> SessionUsage | None` accessor that resolves the live session's JSONL path and delegates to `aggregate_session_usage`; returns `None` when idle; CCR-032 added `_rate_limit_status: RateLimitEvent | None` instance attribute populated in `_consume_events` and reset at all three session boundaries (`new_session`, `continue_session`, `_teardown_locked`); `current_rate_limit_status() -> RateLimitEvent | None` synchronous accessor
- `src/ccr/claude/events.py` — (cross-listed from claude-runtime) CCR-030 added `skills: list[str]` field to `SystemInit` event model to surface the `"skills"` array from the `system/init` JSONL event; CCR-032 added `RateLimitInfo` (camelCase aliases via `populate_by_name=True`, all fields default `None`, `extra="allow"`) and `RateLimitEvent` Pydantic models; both added to `_KnownEvent` discriminated union, `ClaudeEvent` type alias, and `__all__`
- `src/ccr/claude/usage.py` — **new (CCR-023)**. `SessionUsage` frozen dataclass + `aggregate_session_usage(jsonl_path)` walker; private `_Accumulator` + helpers `_absorb_result` / `_absorb_assistant_turn`. Aggregates input/output tokens, cache tokens, tool-use count, success-turn count, total elapsed (with `duration_api_ms` fallback), and total cost USD across every `result` event in the JSONL. Forward-compatible: `UnknownEvent` lines and parse errors fall through silently.
- `tests/test_claude_usage.py` — **new (CCR-023)**.
